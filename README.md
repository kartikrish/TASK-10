---
👋 Introduction

This project is made to help beginners understand exception handling in Java.
Exception handling helps a program handle errors safely without crashing.

---

❓ What is an Exception?

An exception is a problem that happens while the program is running.

Examples:

Dividing a number by zero

Entering wrong input

File not found

---

🎯 What You Will Learn

This project teaches:

What runtime exceptions are

How to use try and catch

Why finally block is important

How to create your own exception

How to use throw keyword

Difference between checked and unchecked exceptions

How to show proper error messages
